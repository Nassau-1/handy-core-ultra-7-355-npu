# Windows Intel NPU

This fork supersedes the environment-variable prototype. Use the bundled
**Whisper Turbo INT8 · Intel NPU** entry. External Python, model directories and
`HANDY_OPENVINO_*` variables are not used.

See [README](../README.md), [architecture](architecture.md), [Intune operations](operations.md)
and [hardware acceptance](acceptance.md). The original prototype remains in Git
history at d05dce78d878b59733c4dfc6528484eb05436790.
